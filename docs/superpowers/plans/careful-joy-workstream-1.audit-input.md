redesign the role-aware staff shell, then update the UI lab and visual snapshots without changing
product workflows.

1. Preserve Plus Jakarta Sans Variable, tabular numerals and the specified type hierarchy.
2. Apply Sea Glass light values, complete green-charcoal dark mode and contrast-compliant service hues.
3. Use specified radius, spacing, depth, focus and reduced-motion contracts.
4. Evolve Button, Card, Sheet, StatusCallout, InitialsAvatar and PageHeader.
5. Add approved Motion and Radix interaction boundaries only behind shared components.
6. Redesign AppShell with labelled role-aware navigation and composed system status.
7. Update UI lab and reviewed visual snapshots before feature pages.
8. Preserve scheduling, auth, roles, tenant boundaries, keyboard behaviour and responsive contracts.
